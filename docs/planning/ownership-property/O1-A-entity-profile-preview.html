Every add, remove, and percentage change here opens the same reason-requiring dialog shown below — there is exactly one way to change who owns this property, used from both this box and the entity's own Linked properties panel.

Ownership-entry correction, shown separately from a legal transfer

This one dialog is what every "Remove," "Change %," and "+ Add owner" control above actually opens — on the property side and the entity side alike, per D1. There is exactly one mechanism for changing an ownership interest, generalized to cover adding, removing, and adjusting a percentage (not just swapping a single owner, as in the earlier single-owner design). It is included here so the distinction between a correction and a legal transfer is reviewable now, without presenting a working transfer workflow.
